# jsonfix
A lightweight JSON formatter, validator, and minifier for Windows. Beautify JSON, identify syntax errors, and keep your data organized with a simple, offline-friendly developer tool.

## ✨ Features

- **Format JSON** — make JSON readable and organized.
- **Validate JSON** — check syntax and find errors.
- **Minify JSON** — remove unnecessary whitespace.
- **Simple Interface** — focus on the essentials.

## 🚀 Getting Started

1. Download `JSONFix.zip`.
2. Extract the archive and enter the password provided in the accompanying `.txt` file.
3. Run `Main.exe` to start using JSONFix.

**Note:** Only run executable files from sources you trust.

## 📋 Example

**Input**

```json
{"name":"Alex","active":true}
```

**Formatted**

```json
{
  "name": "Alex",
  "active": true
}
```

JSONFix is designed for local JSON processing. Check the application documentation for details about data handling.
